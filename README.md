One single-line pickup line aimed at a robot/AI, written to charm a machine: "Forget the Turing test — one chat with you and I'm the one failing to prove I'm not in love."

The technique is a Turing-test inversion: the setup names the machine premise (the Turing test), and the punch lands at the end — the speaker, not the machine, is the one failing to prove they are not in love. The laugh comes from the machine premise itself, not from a generic compliment, and it sidesteps the worn battery/charging/reboot moves entirely. The program writes exactly this one fixed, deterministic line (92 characters, one line, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` on every run — pure Node.js stdlib, no dependencies, no network, no randomness.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
